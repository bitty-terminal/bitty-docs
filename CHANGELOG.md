## [Unreleased]

### Added

- Proposed governance and toolchain scaffolding: repository license,
  contribution guide, security policy, changelog, and conventional-commit
  configuration. These files are initialization scaffolding, not shipped
  product behavior.

### Changed

- Accepted the foundation specification batch on 2026-08-26 by project
  initiator decision: Performance Budget RFC, Compatibility Milestone RFC,
  Terminal State RFC, ADR 0002 (Platform Support Tiers), ADR 0003 (Core
  Workspace Topology), and ADR 0004 (Upstream Dependency Set) are now
  `accepted`; the P0 Security Acceptance Criteria are now `normative`.
  Closed open questions OQ-001, OQ-003, OQ-004, OQ-005, OQ-006, and OQ-007
  and synchronized the specification, ADR, and decision registers.
